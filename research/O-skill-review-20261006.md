# 东方剑修技能审阅与整理

用户反馈：mod.io 包的职业选择和图标已正常，但技能入口、说明和动态表现仍未达到预期。本轮授权为 review、删除或合并不合理技能、修改玩家说明，并在修改完成后进行 Toolkit 验证；用户随后明确授权全部验证后更新既有 mod.io 模组并更新本地安装。本记录截至2026-10-07：技能整理和Toolkit验证已完成，既有mod.io条目及本地安装均更新至1.0.0.5；正式游戏SE战斗和原创动态特效仍待验收。

## 审阅结论与修改

| 问题 | 修改 | 保留的机制 |
|---|---|---|
| 常态剑法之外另授予四个“副手××”容器，玩家难以分辨动作与附赠攻击 | 两种副手追加并入对应常态剑法；六个选项区分主／副手近战与御剑、两种“副手追加” | 四个动作选项分别用选定佩剑计伤；两种追加只耗附赠动作，不产生整套连贯出剑 |
| 3级以后常态近战与入门近身剑术并存 | 常态同时接替御剑术和近身剑术；原ID保留供旧档读取，过期入口在载入／升级时清理 | 各分支常态的近战与远程选择 |
| 天倾有调息与蓄势两个回气入口 | 蓄势的分支回元并入调息，不再授予独立蓄势 | 3级60%、11级70%，战后回满；动作费用不变 |
| 太玄4级后入门护体与清辉返照作用重复 | 清辉返照接替剑气护体 | 较强护体与反击；其他分支保留入门护体 |
| 技术规格直接充当技能说明，包含“覆盖”“独立攻击阶段”等措辞 | 重写主动、被动、状态和反击文案 | 保留费用、范围、持续、豁免、误伤等构筑必要信息 |
| 继承原版法术同时继承治疗提示、雷鸣豁免提示及双持联动费用 | 明确清除无关继承字段，匹配剑术动画及视觉语义 | 不改变伤害骰、目标规则或实际动作费用 |
| 装备剑的一级角色刚进图时两个技能均灰；职业组件晚于创角装备事件就绪，首次普通攻击才更新持剑状态 | 在关卡玩法就绪和后加入玩家事件重新发现并初始化职业角色 | 真实佩剑、持盾、护甲限制保留；不需要先攻击或重新装备 |
| 原技能入口依赖SE生成的持剑状态，Toolkit未加载SE时正常佩剑也会置灰 | 改用原生主／副手装备查询，并在装备与状态变化时重新计算可用性 | 所有分支禁盾；太玄／行歌禁中、重甲，天倾／血魇允许；副手动作与双剑附赠追加分别判定 |
| 流光追星四段攻击的目标选择不清楚 | 锁定同一敌人，四道气剑分别攻击，整招只收一次费用 | 四次攻击检定与四段伤害，不依赖首剑命中才继续 |
| 天崩剑啸没有明确主目标，也未正确区分主敌与余敌伤害 | 点选主敌，主敌为基础剑击＋32d8，扇形余敌为基础剑击＋18d8，分别攻击 | 只伤敌、主敌压制与击退；主目标不会再重复吃余敌伤害 |

审阅范围包括规格中全部44个命名技能、四支常态的动作／附赠变体、强化与绝技的佩剑选择、癫狂投入、续剑、飞移、疗伤两种费用、全部可见被动与状态说明。内部周期攻击和伤害辅助技能保留为内部实现，不额外授予技能书。癫狂投入保留0—15层选择，避免把自主投入改成固定消耗；气剑、伤害类型、召剑和重点目标具有独立用途，保留并解释。

17门绝技及四支定位、伤害与资源曲线沿用总稿。本轮重点是减少重复入口、澄清操作和修正错误继承；高倍率数值设计没有在缺乏实战数据时另行削弱。

最终文案核对还修复了近战／御剑副手追加共用本地化键导致说明互相覆盖、无生近战续剑误写24米射程的问题。七项被动明确10／11级成长值。血魇的坏死／力场可切换伤害不再显示固定坏死预览，避免与玩家的实际选择矛盾。
