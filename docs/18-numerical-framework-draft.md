# 东方剑修：数值框架初稿

记录日期：2026-09-29（Asia/Shanghai）。

本文承接 [职业设计](10-eastern-sword-cultivator-design.md)、[成长路线](14-level-progression-draft.md) 与 [动作及资源规则](16-actions-and-resources-draft.md)。**剑元容量、进攻费用标准、战斗回气，以及生命、防护、疗伤和癫狂初稿已通过提问卡确认**；后续候选另行标明状态。这里进行纸面设计，游戏内实现与验证仍由另一个 MVP session 处理。

## 1. 沿用的设计目标

- 太玄、天倾、血魇用于独行通关，常态远超原版同等级冒险者；血魇常态弱于太玄与天倾。行歌常态略高于同级冒险者，个人爆发低于前三支，偏重团队协作。
- 5级前三支每个剑术动作三次出手，10级增至四次；行歌两次。进攻强化与所有绝技各占一次出剑机会，主动回气也占一次。
- 基础剑招不耗剑元；9级满元约可支持三门标准费用常规绝技。各招费用按层级分档并可调整。
- 战斗中各支按自己的循环恢复剑元，战后调息可回满剑元；生命恢复另行定价。
- 太玄反击及行歌12级呼应不额外耗元。持续剑域、余威与已确认的团队剑术不需专注或维持费用，同名效果不叠加。

按已确认的容量50、终极20、强化4标准，12级天倾可用20＋20＋4的预算组合两门终极与一门强化，共44元；剩余一次出手机会仍可使用常态剑法。这个示例解释标准资源预算，逐招最终费用仍须填写。

用户选择4／10／20的标准费用。强化／终极3／18与6／24两种备选未采用；特殊招式仍可逐招调整。

保守回气备选未采用：共同调息30%、太玄稳定10%、天倾蓄势40%；血魇每份1元、斩杀2元；行歌常态1元、协作1元。

## 5. 生命、防护与恢复：已确认初稿

本节数值已通过提问卡确认。用户选择更厚的前三支生命，以及更强的主动疗伤；常态防护沿用原提案。数值以3级分支基础、4级成熟恢复为起点，11级深化另行设计。

### 生命底子

共同职业生命初稿：1级为10＋体质调整值，此后每个本职业等级增加6＋体质调整值。3级起，职业成长所得生命（包含对应的体质调整）采用分支倍率并向上取整；其他来源额外生命另算。

| 分支 | 已确认生命倍率 | 体质调整＋2、12级本职业基础生命100的算例 |
|---|---|---|
| 太玄 | 1.8 | 180 |
| 天倾 | 2.5 | 250 |
| 血魇 | 1.6 | 160 |
| 行歌 | 1.1 | 110 |

职业基础生命按 `10＋体质调整值＋(职业等级－1)×(6＋体质调整值)` 计算，再应用对应倍率并向上取整；倍率不逐级重复叠乘。算例只按职业公式计算，不把该100生命当作原版所有同级冒险者的实际生命。原提案太玄1.5、天倾2.0、血魇1.4未采用，行歌1.1保留。

### 3级常态防护

以下**护甲等级加值**与被动减伤是分支基础，装备提供的防护另算。血魇癫狂、主动护体与绝技暂时增幅另定。

| 分支 | 已确认常态防护 |
|---|---|
| 太玄 | 额外防护＋6，稳定减伤20% |
| 天倾 | 额外防护＋2，稳定减伤35% |
| 血魇 | 额外防护＋2，稳定减伤20%；持有癫狂每层增加减伤率2个百分点，无视敌人借机攻击保持 |
| 行歌 | 自身额外防护＋1；与同伴并肩时，双方额外防护再＋1，并各减伤10% |

减伤覆盖**武器、法术、持续和环境等各类伤害**。血魇先将常态减伤与癫狂提供的百分点相加，再与其他减伤逐项相乘。例如满15层的血魇职业减伤为20%＋30%＝50%，再获得一项20%减伤时，剩余伤害为 `原伤害×0.5×0.8`，合计减伤60%。主动付出的生命费用不享受减伤。其他新增临时减伤沿用与职业减伤逐项相乘的规则。

行歌并肩保护覆盖**3米内实际队友**，同时作用于自己和范围内每名队友；自身常态护甲等级＋1保留，生效时双方再＋1并减伤10%。多个行歌的同名并肩保护不叠加；离开范围即移除，重新进入即恢复。6米并肩备选未采用。

血魇补充护身已确认：**3级起实际伤害10%凝成血衣护盾，累积上限自身最大生命20%，持续2轮、再次取得刷新**。护盾承接减伤后的伤害，没有实际损失自身生命就不取得受伤癫狂。4级穿行与6级追斩发生实际位移后，额外护甲等级＋2、持续2轮，同名不叠加。血衣15%转化、30%上限备选未采用。

### 生命恢复

主动恢复按4级成熟形态确认以下费用与效果，使用附赠动作。太玄、血魇对应被动恢复从3级学习；天倾与行歌3级先学习下列初阶版本，4级替换为成熟版本。

| 分支与来源 | 已确认费用与恢复 |
|---|---|
| 太玄缓慢自愈 | 自身回合开始回复最大生命5%，不耗剑元 |
| 太玄主动疗伤 | 6元，回复自身最大生命40% |
| 天倾3级初阶回生 | 5元，回复自身最大生命35%；4级替换为成熟回生 |
| 天倾强力回生 | 10元，回复自身最大生命75% |
| 血魇伤敌饮血 | 回复实际伤害的20% |
| 血魇斩杀额外生命 | 回复自身最大生命10%，在伤敌饮血之外结算 |
| 血魇备用疗伤 | 可付6元或3层癫狂，回复自身最大生命40% |
| 行歌3级初阶救急 | 4元，为自己或一名同伴回复目标最大生命15%；4级替换为成熟救急 |
| 行歌救急治疗 | 6元，为自己或一名同伴回复目标最大生命30% |

生命恢复**向上取整，不超过最大生命**。主动疗伤在战斗内外均可使用，资源与动作足够即可重复施展，不额外设置每场次数；太玄被动自愈仍在战斗自身回合开始结算。较低成熟主动恢复原稿（太玄／血魇30%、天倾60%、行歌25%）未采用；费用与被动恢复沿用原稿。3级天倾50%、行歌20%的较强初阶备选也未采用。行歌9级接受治疗增幅为50%，详见第7节。

## 6. 血魇癫狂：已确认初稿

### 积蓄与持有

| 项目 | 已确认初稿 |
|---|---|
| 上限 | **15层**；10层上限原提案未采用 |
| 普通实际受伤 | 每次获得1层，经过防护后确实损失自身生命才触发 |
| 重伤额外 | 该次损失达到自身最大生命10%时，再获得2层，合计3层 |
| 斩杀额外 | 每次斩杀获得2层，另有生命与剑元奖励 |
| 持有命中增幅 | 每满2层命中＋1，15层时＋7 |
| 持有剑招伤害增幅 | 每层＋5%，15层时＋75% |
| 持有减伤增幅 | 每层增加减伤率2个百分点，15层时多30个百分点 |

8级主动耗血为独立获取方式，不重复领取普通受伤层数；获得层数仍受上限约束。受伤事件的分段、持续伤害来源与斩杀归属之后补齐。

### 绝技投入与主动耗血

7级反扑与12级终极仍可零癫狂施展基础威力，玩家可自主选择额外消耗量；每消耗1层，**为当次绝技额外增加10%威力**。当次绝技的持有增伤按**消耗前层数快照**计算，与投入增伤相加；施展后，后续持续强化按剩余层数计算。例：15层投入10层，当次增伤75%＋100%＝175%，之后余5层、持有增伤25%；全部15层投入则当次增伤225%。每层15%消耗增幅及按消耗后层数计算两种备选均未采用。

8级强化：**附赠动作，付出自身最大生命10%，获得4层，不耗剑元**。生命费用向上取整，不得将自身生命降至0；不足以支付时不能施展，所得受15层上限约束。耗血20%取得8层的可选档位未采用。

4级备用疗伤的癫狂路径为消耗3层，恢复自身最大生命40%；使用后持有强化相应降低。

纸面审阅补充：7／12级投入癫狂时，**当次绝技的癫狂命中加值也按消耗前层数快照**，所有需要命中判定的阶段沿用该快照；满15层全部投入时，当次各命中阶段仍有＋7。后续其他剑术及持续防护按剩余层数。命中按消耗后层数的备选未采用；不将这项命中增幅改为豁免难度加值。

### 持续与跨战斗

**战斗内不自然衰减；脱离战斗后每6秒减少1层，重新进入战斗停止自然衰减。**倒地待救或死亡时清零。非战斗时允许使用8级主动耗血积蓄，作为战前准备。战斗结束立即清零、战后完全保留两种备选未采用。

## 7. 抗控与行歌伤害分担：已确认初稿

### 抗控与解控

- 前三支3级，对已覆盖的身体与心智控制抵抗判定获得**优势并额外＋4**；常态额外＋6备选未采用。
- 前三支5级与行歌8级主动解控均为**4剑元、附赠动作**，一次清除目标全部已覆盖控制，自身受控时仍可按专门例外自救。
- 成功后持续**2轮**，对这些控制的抵抗额外＋2；行歌施展时该保护同样作用于受援同伴。这是提高抵抗，不是免疫。
- 前三支4级自动保障仍为每轮一次，消耗可用反应而不耗剑元，在控制施加前检查并化解；具体控制清单继续整理。

### 行歌9级多人护身

| 项目 | 已确认数值与规则 |
|---|---|
| 费用与动作 | 10剑元，一次出剑机会 |
| 持续 | 4轮 |
| 保护范围 | 6米内实际队友；范围内生效、离开停止分担 |
| 分担比例 | 队友自身防护后的剩余伤害**40%**转移给行歌，再由行歌自己的防护化解；50%备选未采用 |
| 自身承伤强化 | 额外获得30%减伤，与其他减伤按已确认乘算规则衔接 |
| 自身恢复强化 | 接受治疗收益提高50%，不增加缓慢自愈 |
| 同名叠加 | 不叠加 |
| 维持与结束 | 不需专注、不额外耗元；普通受控继续，倒地待救或死亡结束 |

分担的伤害来源、转移伤害取整、多个行歌之间的转移关系与施展细节继续整理。

## 8. 剑术判定、启蒙与持续时间：已确认初稿

### 剑术判定

- 实体剑击命中与伤害使用**感知或原武器属性中较高的调整值**；无实体佩剑的气剑使用感知。
- 剑道命中加值＝熟练加值＋对应属性调整＋职业剑术加值，其他装备或招式加值分别结算。
- 剑道豁免难度＝8＋熟练加值＋感知调整＋职业剑术加值。
- 1—2级职业剑术加值＋1；3级起**太玄＋6、天倾＋4、血魇＋3、行歌＋1**。原提案前三支＋4／＋3／＋2未采用。
- 癫狂及招式增益按已确认用途另加；癫狂每满2层的＋1属于命中增幅，不自动新增豁免难度效果。

### 共同启蒙

| 项目 | 已确认初稿 |
|---|---|
| 1—4级剑术动作 | 每个剑术动作一次出手，5级起进入已定分支连贯次数 |
| 1级被动剑气防护 | 护甲等级＋1 |
| 2级初阶护体 | 附赠动作、2剑元、持续2轮，额外护甲等级＋2并减伤20% |
| 分支后的保留与替换 | 3级分支常态防护替换1级被动；2级主动护体保留，与常态防护按已定规则叠加 |

2级护体30%减伤备选未采用。共同护体没有自动取得太玄4级护体反击；反击仍由其对应招式提供。

5级御剑飞行数值已确认：**起飞前3米内无敌，附赠动作、不耗剑元，获得本次独立24米移动额度，不额外扣常规移动距离**。可跨越沟壑、高低差与地面障碍，墙与封闭门阻挡；目的地须可落脚，途中接近敌人仍能完成。36米飞行备选未采用。

| 行歌12级团队剑术 | 4轮 |

同名持续效果不叠加；重复施展按此前规则刷新，不重置已使用的每轮次数，行歌常态标记重施重置首次奖励资格的专门规则保留。四门持续绝技5轮备选未采用。各招剩余持续的统一计时方式与其他临时增益时间继续整理。

## 9. 基础剑击与常态伤害：已确认初稿

### 基础剑击

采用**武器本体＋分支剑气**结构，完全独立招式伤害备选未采用。为后续招式规格统一记号，定义 `W` 为一次基础剑击：

- 实体剑：所用武器基础伤害骰＋感知或原武器属性中较高的调整值。
- 纯气剑：**2d6＋感知调整值**。
- 各招再独立安排额外剑气、基础剑击倍率与攻击段数，不能把常态额外骰自动再加到所有强化或绝技里。
- 装备附加效果、多段触发及双持具体取值继续单独整理；该定义没有将同一招的每项附加伤害变成新的有效剑击。

### 四支常态额外剑气

每次出手、每名被命中敌人分别结算基础剑击与以下额外伤害。用户采用原提案，前三支每档再加一骰备选未采用。

| 职业等级 | 太玄照隙 | 天倾逆锋 | 血魇掠血 | 行歌问路 |
|---|---|---|---|---|
| 3—4 | W＋2d8 | W＋3d8 | W＋2d6 | W＋1d4 |
| 5—9 | W＋3d8 | W＋4d8 | W＋3d6 | W＋1d6 |
| 10—12 | W＋4d8 | W＋5d8 | W＋4d6 | W＋2d6 |

天倾多敌攻击按每名命中敌人分别结算。血魇持有癫狂的剑招伤害增幅另加；行歌协作进攻增益与队友自己的伤害分别处理。11级基础深化将另行填写，不默默改变已选基础骰档位。

### 伤害类型

实体武器本体保留自己的伤害类型。太玄气剑与额外剑气为**力场**；天倾与行歌额外剑气为**力场**。血魇气剑与额外剑气默认**坏死**，允许主动改用力场；类型切换的使用细则继续整理。四支统一力场备选未采用。

本组只确定伤害结构与类型，未通过这一选择给所有招式追加无视抗性或免疫；个别招式的破防规则另行确认。

职业与招式提供的**百分比增伤先相加，再对对应剑击伤害计算**；装备效果按各自规则另外结算。血魇投入癫狂的快照与增伤见第6节。

### 启蒙与常态距离

单体御剑射程**18米**；近身单体按所持剑的攻击距离。天倾常态近身为前方**6米扇形**，御剑为**长12米、宽2米直线**，每名命中敌人分别结算伤害。命中后目标进行力量抵抗，失败则击退**2米**；18米天倾直线备选未采用。具体扇形角度及无实体剑的近身距离继续整理。

### 破绽与跟进增幅

太玄对破绽目标的自身后续剑术**命中＋2、伤害＋20%，并无视目标的伤害抗性减免，不直接突破伤害免疫**。覆盖常态、强化、绝技、反击与剑域气剑；持续3轮，照隙命中刷新，不叠加幅度。

行歌跟进机会使队友对标记目标**命中＋2、伤害＋15%**，持续3轮；已覆盖的武器与直接伤害法术均受益，首次协作回气后增益继续保留。问路重施刷新持续与每名同伴首次奖励资格，不叠存多份。增伤太玄30%／行歌20%的较高备选未采用。

## 10. 终极标尺、护体叠加与自动攻击：已确认

- 终极纸面标尺：12级、感知20、无装备附伤或其他招式增益，以天倾终极对主要敌人的全部攻击阶段计，全部命中且未被减免时，**基础平均总伤害180—240**。300—400与500—600备选未采用；此为设计参照，不是游戏验证结果。
- 2级共同护体、太玄4级护体与7级护身为**同一护体系列，取最强**。护体强度与反击保留较强者，弱招不刷新强招持续，重施同名刷新持续；常态防护另行生效，7级首次伤敌与击退照常结算。全部共存叠加的备选未采用。
- **护体反击不触发另一方护体反击，御剑呼应不触发新的御剑呼应**；已确认7级队友协同可触发12级呼应的例外保留。血魇剑域与各招正常伤敌饮血、回元继续按原规则结算。

## 11. 10—11级成长：已确认初稿

### 10级常规绝技进阶

三门常规绝技费用保持10元；由施展者造成的直接伤害和后续剑击／余威伤害增加15%，与其他职业及招式百分比增伤相加。行歌7级队友攻击不自动取得此15%增伤；行歌9级分担由40%提高至45%、接受治疗增幅由50%提高至75%。前三支每个剑术动作四次出手，行歌沿用两次。进阶增伤20%的备选未采用。

### 11级基础深化

四支职业剑术加值再＋1，同时作用于命中与剑道豁免难度；成为太玄＋7、天倾＋5、血魇＋4、行歌＋2。下表各值**替换**对应早期数值，不把新旧值重复叠加。

| 分支 | 11级起采用的数值 |
|---|---|
| 太玄 | 常态护甲等级＋7、减伤25%；自身回合开始自愈最大生命6%、稳定回元容量25%；太玄主动调息恢复容量50% |
| 天倾 | 常态减伤40%；主动蓄势恢复容量70%；成熟回生恢复最大生命80% |
| 血魇 | 常态减伤25%；按实际伤害25%饮血；每份有效剑击回2元、每次斩杀额外回4元；癫狂减伤仍先与常态相加 |
| 行歌 | 并肩额外护甲等级＋2、减伤15%；自身常态护甲等级＋1仍保留；每次常态出剑回2元、成功协作每份回3元 |

其余已确认规则及费用保持，出手次数沿用10级。仅加强回气与剑术加值、保留早期防护恢复的备选未采用。前文各表记录初学形态；11级起按本表替换，行歌9级则先套用10级进阶。
