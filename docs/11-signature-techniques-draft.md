## 1. 本轮设计依据

- 持剑与御剑并重；招式可以通过近身剑法或远程御剑展现。两种方式的距离、动作消耗和效果差别未定。
- 四支统一以感知为主属性；剑类攻击取感知或原武器属性中较高者，剑道技能仍以感知为核心，具体适用与计算规则待定。太玄、血魇以气为核心，凝气成剑并可增强佩剑；天倾、行歌以实体佩剑为主。
- 已确认“御剑术”为入剑道时首先学习的共同初级技能／戏法；选择分支后，以对应分支的常态招式替换。
- 基础剑招不消耗共同主要资源；强化与绝技消耗资源，暂称“剑元”。
- 四支能在战斗中恢复剑元，战后调息回满。剑元的名称、上限、费用和恢复数值未定。
- 太玄、天倾、血魇以单人承担整支队伍职责为目标，常态就具有超凡战力；行歌常态略高于原版同等级冒险者，更倾向团队协作。
- 个人爆发质量目标为天倾 > 太玄 > 血魇 > 行歌，四支不要求个人强度相等。
- 血魇伤敌回气、斩杀获额外恢复、自身受伤积蓄癫狂；癫狂持续强化战力，部分绝技消耗层数获得额外爆发。
- 本轮已确认绝技的默认出手节奏：资源足够即可施展，不额外等待准备回合；招式本身的动作、资源和目标要求仍需满足，具体规则待定。
- 本轮已确认血魇可自主选择消耗癫狂的量，少量消耗保留持续强化，大量消耗追求爆发；7级与12级绝技在零癫狂时也可用剑元施展基础威力，癫狂仅作额外增幅。具体可选数量与消耗方式未定。

已确认5级每个剑术动作**前三支三次出剑、行歌两次**，**10级前三支增至四次**；主动伤敌的强化与绝技均各占一次出剑机会，出手间可切换目标与持剑／御剑。**主动护体、疗伤、血魇主动耗血积蓄癫狂及主动解控使用附赠动作；主动调息／蓄势占一次出剑机会**。反应、后续触发与其他动作细则，以及伤害骰、伤害类型、豁免、准确范围与次数限制仍待确定，见 [动作与资源草案](16-actions-and-resources-draft.md)。共同与分支学习节点见成长记录。下文的护体、破绽、重压、合击等词描述设计意图，尚不是具体游戏状态或代码定义。

## 2. 共同启蒙戏法：御剑术

### 已确认的定位与获得方式

- **名字**：御剑术。
- **类型**：最初级技能／戏法，是四支共同的启蒙剑法。
- **获得**：初入剑道、职业起始时学习，是所学的第一个剑法；具体成长表尚未填写。
- **资源定位**：继承基础剑招不消耗剑元的既定规则，按戏法定位不消耗法术位；使用动作、施展条件与数值仍待确定。
- **进阶**：选择分支后，由该支的进阶常态招式替换，作为同一门启蒙剑法在不同修行道路上的发展。
- **飞剑来源**：已确认以实体佩剑入门，初入剑道时御使自己的佩剑；太玄、血魇随后发展为以气为核心，天倾、行歌继续以实体佩剑为主。

### 已确认的基础攻击形式

已通过提问卡确认**单体飞剑归手**：御使自己的实体佩剑攻击一个目标，完成攻击后收回。攻击距离、伤害类型、命中规则、随等级成长方式与动画仍待确定。

分支阶段已经确认太玄、血魇以气为核心，天倾、行歌以实体佩剑为主。详见 [属性与装备记录](13-attributes-and-equipment-draft.md#4-分支的御剑来源)。

“御剑术”的加入不改变持剑与御剑并重的共同战斗形式。分支变体是否将近身剑术与御剑形式放在同一个技能中，仍待讨论。

### 共同启蒙的配套能力

- **1级基础被动剑气防护**：与御剑术、近身基础剑术一同构成起步能力，具体防护形式与强度待定。
- **2级剑元与调息**：学习管理剑元；战中可基础回气，战后通过调息回满剑元。调息的动作、恢复量与具体使用条件待定。
- **2级共同初阶护体**：消耗剑元短时加强防护，具体效果与名称待定；4级另学习各支的首个分支强化招式。
- **1—2级常态略高于原版同级冒险者**，3级后形成分支强度与玩法差异。除已确认替换的御剑术之外，其他共同能力在选择分支后的保留、替换或进阶方式待定。

### 分支替换关系

| 修行阶段／分支 | 常态剑法 | 已确认的主要效果方向 |
|---|---|---|
| 尚未选择分支 | **御剑术**（名称已确认） | 单体飞剑归手，御使实体佩剑攻击一个目标后收回 |
| 太玄 | **照隙**（候选名） | 精准攻击单敌、揭开破绽，提高自身后续剑术的命中、防护穿透与伤害 |
| 天倾 | **断岳**（候选名） | 持剑扇形横扫、御剑直线贯斩，均以强横剑势伤敌并击退 |
| 血魇 | **掠血**（候选名） | 攻击单敌，借伤敌恢复生命与剑元 |
| 行歌 | **问路**（候选名） | 攻击单敌，同伴跟进攻击同一敌人时更精准、伤害更高，行歌获得协作回气 |

替换结构、3级选择分支与四支常态的主要效果方向已经确认；四个名字仍为候选，具体触发、增幅、范围与次数仍待确定。进阶变体是否仍统一标为戏法，以及重置／改选分支时的具体处理均待定。

## 3. 太玄：看破、护身、集中一点

主要回气已确认：每回合吸纳天地灵气，主动调息集中恢复。代表招式强调从容、精纯和单体爆发。

### 常态：照隙

- **画面**：凝神之后一剑点出；近身时剑锋贴着防御薄弱处进入，御剑时飞剑循着灵气的缝隙刺向目标。
- **用途**：精准攻击单个敌人，并识破其防御中的一个破绽。
- **主要效果已确认**：常态剑击**命中即可揭开破绽，即使伤害被完全减免也可生效**；自己的后续常态、强化、绝技、护体反击与剑域气剑均可利用破绽，**提高命中、防护穿透与伤害**。效果持续期间多次剑术均受益，照隙再次命中刷新持续，增幅不叠加。
- **消耗方向**：不消耗剑元；动作等消耗待定。
- **循环作用**：普通战斗就能有效伤敌，并为关键时刻的集中爆发铺垫。
- **待定**：破绽持续多久，以及命中、防护穿透与伤害的具体增幅与计算。绝技可以独立施展；目标已有破绽时按已确认的后续剑术规则受益，详见 [常态状态规则](16-actions-and-resources-draft.md#8-常态破绽与跟进机会逐项确认)。

### 强化：清辉返照

- **画面**：剑气环绕周身，清辉浮动；近身以剑势承接攻势，御剑以回旋飞剑形成护体。
- **用途**：在受压时保护自己，并将化解的攻势转成反击机会。
- **主要效果已确认**：消耗剑元短时加强**攻击偏转与减伤**，使攻击更难命中自己，并化去部分来袭伤害；化解攻势后对攻击者精准反击。
- **反击规则已确认**：护体期间，敌人的近身、远程攻击或直接伤害法术未命中，或命中后被剑气减伤，都可反击明确的来袭者。**每次符合条件的攻势均提供反击机会，玩家决定是否出手，不消耗反应、出剑机会或附赠动作**。
- **多段、费用与命中已确认**：每个符合条件的独立攻击阶段都可反击，同一段附加伤害合并计算；反击不额外耗元，独立进行高精准度的命中判定，仍可能落空。
- **消耗方向**：施展护体消耗剑元并使用附赠动作；具体开启费用、持续时间与强度待定。
- **循环作用**：玩家可以选择把力量留给绝技，也可以先消耗力量稳住战局。
- **待定**：偏转、减伤与反击的具体强度、持续、距离、开启费用及其他攻击来源细则。当前主要规则见 [动作与资源记录](16-actions-and-resources-draft.md#6-太玄护体反击逐项确认)；生命恢复仍由独立能力承担。

### 绝技：玄极·一线天

后续已将该名作为12级终极的候选，并确认**气剑归一、沿线贯穿、穿墙伤敌，首先命中的敌人伤害最高，其余按顺序递减**。下列内容保留首轮草案的创作依据，当前扩展与确认范围见 [太玄绝技记录](15-ultimate-techniques-expansion-draft.md#2-太玄精准反制剑域分工已确认)。

- **画面**：万缕剑气归于一线，天地仿佛在刹那间静止；剑锋贯穿一个目标，余光随即收敛。
- **用途**：对单个重要敌人释放高度集中的点爆发。
- **效果草案**：消耗大量剑元，以极高质量的剑击穿透目标的护体与防御。若照隙创造了破绽，可考虑额外强化穿透或伤害。
- **消耗方向**：大量剑元；具体规则待定，不要求必须攒满或强制先用照隙。
- **强度方向**：个人爆发质量仅次于天倾，力量主要集中于一个目标。
- **待定**：如何体现“穿透任何防御”的最高境界，哪些防御、抗性或免疫属于可穿透范围；不直接假定必定命中、必定杀死或无条件忽略所有游戏规则。

## 4. 天倾：贯穿、镇压、天地倾覆

主要回气已确认：主动蓄势，不依赖敌人配合。蓄势属于待细化的回气能力，不占本轮三个代表招式的名额。

### 常态：断岳

- **画面**：沉重剑势正面斩出，近身横断前方，御剑时化为贯穿一线的巨大剑光。
- **用途**：凭常态力量压制正面敌人，具有比太玄更明显的范围感。
- **主要效果已确认**：以强横剑势攻击一小片区域，并击退敌人；**近身采用扇形横扫，御剑采用直线贯斩**。
- **消耗方向**：不消耗剑元；动作和击退判定待定。
- **循环作用**：即使尚未蓄势，天倾也能靠普通剑招抵抗围攻。
- **待定**：扇形角度、直线宽度与距离、击退强度、判定，以及常态招式是否可能误伤。

### 强化：镇山河

- **画面**：剑势压向选定区域，空气与地面仿佛同时变得沉重，范围内的敌人承受向下镇压的力量。
- **用途**：范围伤害与战场压制，为继续蓄势或施展更强绝技争取空间。
- **主要效果已确认**：消耗剑元打出一片范围剑势，造成高额伤害，并以重压**减速、削弱敌方进攻**，为蓄势或继续出剑争取空间。
- **消耗方向**：消耗剑元；控制表现与持续时间待定。
- **循环作用**：以主动出手压住战场，不把防守完全建立在承受伤害上。
- **待定**：范围、持续、伤害与减速／进攻削弱的具体强度、判定和动作；击倒、额外防护削弱等候选效果未随本次选择确认。

### 绝技：天倾·覆八荒

后续用户已将12级终极改为**八方灭阵、天地剑劫**两门，并确认较轻误伤：敌人完整伤害，同伴与中立较低伤害。此名称与下列内容保留为首轮草案的创作依据，当前设定见 [绝技扩展记录](15-ultimate-techniques-expansion-draft.md)。

- **画面**：蓄积剑势向上冲天，随后化为摧毁一片战场的倾覆剑光，落下时震荡四周。
- **用途**：释放四支中最高质量的个人爆发，以巨大范围力量扭转战局。
- **效果草案**：消耗大量剑元，对选定区域造成毁灭性的剑击，并伴随强烈的战场冲击效果。
- **危险性草案**：作为最强剑法的候选之一，此招会波及范围内的友军和中立单位，施展前需能明确看到波及范围。
- **消耗方向**：大量剑元；是否与本次蓄势深度额外关联待定，不额外默认必须透支生命。
- **强度方向**：伤害、效果与爆发质量的总体定位最高，范围能力显著。
- **待定**：冲击效果、准确范围与误伤规则；此首轮选用范围绝技展示天倾，不排除后续增加最顶级的单体剑法。

## 5. 血魇：饮血、穿行、癫狂释放

主要循环已确认：伤敌按实际伤害比例回血，瞬间招式每段有效剑击都回元，斩杀额外奖励生命／剑元／癫狂；经过防护与减伤后实际损失自身生命，才被动积累癫狂，**每次受伤获得基础层数、重伤再获得额外层数**。癫狂持有时就**提高命中、剑招威力与承伤能力**；部分绝技消耗层数提升爆发。8级另获得主动付出生命积蓄癫狂的强化招式；9级剑域开域立即攻击一次，之后自身回合开始攻击域内敌人。已确认的饮血、回元、癫狂层数与重伤阈值见 [数值框架](18-numerical-framework-draft.md)，其他来源细则继续讨论。

### 常态：掠血

- **画面**：剑锋切入目标后带出血色剑气，近身时贴身掠过，御剑时飞剑割开目标后折返。
- **用途**：持续伤敌并启动饮血回气循环。
- **主要效果已确认**：攻击单个敌人，借伤敌恢复生命与剑元，启动饮血回气循环；具体恢复条件、数值与限制待定。
- **消耗方向**：不消耗剑元；生命恢复的具体条件与数值待定。
- **循环作用**：面对单个强敌也可以靠伤敌持续取得力量，斩杀另给奖励，不把运转全部绑定击杀。
- **待定**：生命恢复量、具体伤敌判定与触发限制。面对无血目标仍可掠夺生机、魂息或魔力而恢复生命与剑元的方向已经确认，详见 [生存与协作草案](12-survival-and-teamwork-draft.md)。

### 强化：血影穿身

- **画面**：身影与血色剑光一同穿过战场；近身随剑突进，御剑时以飞剑引路完成一次穿行。
- **用途**：主动接敌、摆脱包围、追击受伤目标。
- **主要效果已确认**：消耗剑元，沿选定路线**快速突进**，穿过敌人并攻击沿途目标，抵达选定终点；伤敌可获得分支的饮血收益。
- **消耗方向**：消耗剑元；距离、沿途命中数量、终点限制与动作分配待定。
- **循环作用**：把回气与重新选择战斗位置联系起来，帮助血魇在围攻中持续作战。
- **已确认的分支支持**：血魇常态无视敌人的借机攻击，正常走位与此招穿行都受益；该能力不只属于“血影穿身”。
- **待定**：路线与终点选择、距离、可跨越的地形／障碍、沿途命中与恢复收益的限制；穿行表现已选快速突进，未选化影瞬移。

### 绝技：血魇·无生

本节保留首轮代表招式。当前已确认12级以气凝血影同时围杀选定敌人，目标少时可集中围杀；零癫狂也可用剑元施展基础威力，癫狂自主投入用于额外增幅。当前规则见 [绝技扩展记录](15-ultimate-techniques-expansion-draft.md#4-血魇追斩反扑掠夺分工已确认)。

- **画面**：血色剑影围绕选定敌人连续交错，狂乱剑意从自身爆发而出；既能集中围杀一个强敌，也能向多个敌人展开追斩。
- **用途**：把积累的癫狂主动释放成高强度猎杀爆发。
- **效果方向**：以剑元施展连续剑击，可自主投入癫狂层数获得额外威力。伤敌和斩杀仍按已确认的分支方向给予收益，具体结算限制待定。
- **消耗方向**：剑元＋可自主投入的癫狂层数。已确认零癫狂也可施展基础威力，少量或大量投入可换取额外增强；具体可选数量、消耗方式及额外威力数值待定。
- **强度方向**：爆发很高，但总体质量低于太玄、天倾；区别主要在猎杀过程、伤敌收益与癫狂释放。
- **待定**：目标与追斩次数、单目标时的伤害分配、资源收益上限。不默认斩杀能无限增加行动或连续释放。

## 6. 行歌：试探、接应、共同出剑

主要回气已确认：自身正常剑招提供基础回气，与同伴合击、接应、保护时有额外奖励。

### 常态：问路

- **画面**：近身虚实相间地试探出剑，御剑时以轻快飞剑牵动目标的防守。
- **用途**：正常伤敌，并为同伴创造跟进机会。
- **主要效果已确认**：攻击单个敌人，按分支规则提供基础回气，并为同伴后续跟进创造进攻机会；**同伴攻击同一敌人时更精准、伤害更高，行歌获得相应协作回气**。
- **施加与回气规则已确认**：每次常态出剑都提供基本回气，未命中亦可；**命中即可施加跟进机会，伤害被完全减免也可生效**。同一份机会每名队伍同伴首次命中各提供一份协作回气，重复攻击不重复领取；重新施加刷新持续并重置奖励资格，不叠存多份。
- **增益与消耗方向**：不消耗剑元；持续期间同伴的跟进攻击均有精准与伤害增益，首次命中领取回气后仍保留增益。持续、具体增幅待定；常态出剑恢复1元、协作每份2元已确认。
- **循环作用**：自身有合格的常规战斗能力，有同伴跟进时获得协作收益。
- **适用攻击与组合已确认**：同伴的武器攻击、直接伤害法术，包括7级协同，可享增益并在首次命中／法术生效时领取跟进奖励。同一次同伴出手同时满足常态与7级回气，**只取得较高的一项**。
- **待定**：持续时间、其他攻击来源细则及具体增益。当前触发与刷新见 [动作与资源记录](16-actions-and-resources-draft.md#8-常态破绽与跟进机会逐项确认)，合击与呼应组合见该文第7节。

### 强化：回风解围

- **画面**：剑随风转，迅速接近受压同伴，以剑势打开缺口；御剑时飞剑先到，为同伴划出离开包围的路线。
- **用途**：接应、保护与帮助同伴调整位置。
- **主要效果已确认**：消耗剑元接应**自己或一名同伴**，牵制受援者附近的敌人，并提供短暂防护，帮助渡过危机；**接应／保护成功对同伴生效时即取得协作回气**，不必等待防护化去伤害。
- **消耗方向**：消耗剑元；不默认回气等于或高于消耗。
- **循环作用**：在队友受压时仍能靠自身能力介入战局，把保护同伴变成自己的战斗选择。
- **待定**：牵制与短时防护的具体形式、作用范围、持续、费用；成功对同伴生效的协作奖励为2元。施展使用附赠动作，已确认可以自用，自用收益另行细化；短距转移与救急疗伤没有随本次选择一起确认。

### 绝技：行歌·与君同行

本节保留首轮代表招式。当前已确认12级同时提供自身与同伴的进攻增益，并以御剑跟进同伴的攻击。当前规则见 [绝技扩展记录](15-ultimate-techniques-expansion-draft.md#5-行歌接应合击共守分工已确认)。

- **画面**：持剑者游走战场，飞剑呼应同伴的攻势，多人的攻击在短暂时间内形成连贯剑势。
- **用途**：开启团队进攻窗口，增益覆盖自身与同伴。
- **效果已确认**：自己与队伍同伴均获得进攻增益；自身与每名同伴的主动武器攻击／直接伤害法术命中或生效后，每轮各能引发一次自动御剑呼应，在行歌回合开始重置。多段整次施展计一次，单体攻势追加单体飞剑，范围攻势追加小范围飞剑。
- **消耗与回气已确认**：开启终极占一次出剑机会并支付剑元；呼应不额外耗元、不占出剑机会／附赠动作／反应。一次呼应命中至少一敌，合计奖励一份协作回气，命中多敌不增加份数。独行时自身符合条件的主动攻击也能每轮触发一次。
- **强度方向**：行歌个人爆发低于前三支，团队配合使该招充分发挥价值，不把合击伤害全部折算为行歌个人伤害来颠倒已确认排序。
- **待定**：具体进攻增幅、开启费用、范围／覆盖方式、持续时间、飞剑威力及其他攻击来源细则；呼应命中协作每份2元已确认。当前规则见 [绝技扩展记录](15-ultimate-techniques-expansion-draft.md#12级御剑呼应主要规则已确认)。
