## 1. 沿用的已确认边界

- 持剑与御剑并重；1级学习实体佩剑的御剑术，3级由分支常态剑法替换。基础剑招不消耗剑元。
- 2级学习剑元与调息。剑元主要用于强化招式、主动恢复及绝技；标准费用为强化4、常规绝技10、终极20元，各招可调整。四支共用逐级容量，不加感知容量修正；容量及战斗回气初稿见 [数值框架](18-numerical-framework-draft.md)。
- 战斗中可以恢复剑元，战后通过调息回满剑元；调息回满剑元没有同时确定生命回满。
- 5级常态剑术采用连贯出剑，持剑与御剑都受益；已确认每个剑术动作**前三支三次出剑、行歌两次，10级前三支增至四次**，不同次出手可以切换目标与持剑／御剑。
- 绝技资源足够即可直接施展，无需额外等待一个准备回合；这与招式本身占用什么动作分别处理。
- 血魇持有癫狂层数时立即增强命中、剑招威力与承伤。7／12级绝技可自主投入癫狂取得额外爆发，零癫狂也可用剑元施展基础威力；备用疗伤另有消耗癫狂的路径。
- 血魇8级强化使用附赠动作，付出最大生命10%取得4层癫狂，不耗剑元，不重复领取普通受伤层数，且不得把生命降至0；没有额外确定自伤同时直接回复剑元。
- 5级御剑飞行是独立共同移动能力，**使用附赠动作、不消耗剑元**：起飞前3米内无敌，获得本次独立24米移动额度，不额外扣常规移动距离；途中接近敌人仍可完成，跨越可飞越地形，实体墙与封闭门阻挡，目的地须可落脚。

## 2. 连贯出剑与进攻招式：已确认

以下规则已通过提问卡确认。这里只划分设计上的出手机会，具体游戏实现与验证由另一 session 处理。

| 项目 | 已确认规则 | 尚待细化 |
|---|---|---|
| 5级连贯出剑次数 | **太玄、天倾、血魇每个剑术动作三次出剑，行歌两次** | 11级是否继续增加次数、其他来源动作及武器形式的细则 |
| 10级连贯出剑进阶 | **太玄、天倾、血魇每个剑术动作四次出手，相比5级增加一次；行歌沿用两次** | 新增机会适用同样的招式与切换规则，10级常规绝技进阶同时保留；10级容量40元 |
| 进攻强化与绝技 | **主动伤敌的强化招式与绝技均各占一次出剑机会**；资源足够时，可以在同一个动作内组合施展 | 非进攻强化与配套动作见下表；各招使用频次、持续与内部结算仍待细化 |
| 连贯出剑的选择 | **不同次出手可以切换目标、切换持剑或御剑，也可集中攻击同一目标** | 每次仍须满足该招的距离、目标与使用条件 |

一门多段或范围招式的整次施展占一次出剑机会，其内部攻击次数与目标数量另按该招结算。例如12级天倾在剑元足够且符合各招使用条件时，可以在一个剑术动作内组合8级重斩破甲、八方灭阵与天地剑劫，分别支付每招的资源。不同次出手也可改用常态剑法。

## 4. 分支资源循环：保持原有方向

| 分支 | 已确认剑元恢复主循环 | 与本轮动作规则需要衔接的部分 |
|---|---|---|
| 太玄 | 自身回合开始恢复容量20%，主动调息40% | 百分比向上取整；主动调息占一次出剑机会，不额外耗元 |
| 天倾 | 主动蓄势恢复容量60%，不依赖敌人配合 | 向上取整；占一次出剑机会，不额外耗元，不另加准备回合 |
| 血魇 | 每段、每名被击伤敌人分别恢复1元，同剑附加伤害并入；每次斩杀额外3元、最大生命10%及2层癫狂；伤敌按实际伤害20%恢复生命 | 癫狂积蓄及增幅见 [数值框架](18-numerical-framework-draft.md#6-血魇癫狂已确认初稿)；伤害来源与斩杀归属继续细化 |
| 行歌 | 每次常态出剑恢复1元，未命中亦可；成功协作每份2元 | 跟进、合击、接应／保护及终极呼应分别按第7节计数，同次同伴出手的常态与7级奖励取较高项 |

以上恢复均不超过剑元容量；选择分支后共同调息仍保留。共同主动调息恢复容量40%，占一次出剑机会且不额外耗元。

### 剑元费用层级与容量：已确认

用户通过提问卡选择**按层级分档、每招可调整**，并确认以下费用标准初稿；癫狂、血魇主动生命代价与剑元分别处理。主动疗伤、解控及共同初阶护体分别定价。

| 类别 | 已确认剑元费用标准 | 待细化 |
|---|---|---|
| 基础剑招／分支常态 | **0元** | 其他攻击来源与分支效果细则 |
| 强化招式 | **4元**，特殊招式可单独调整 | 逐招差异；血魇8级生命代价之外是否另有剑元费用 |
| 常规绝技 | **10元**，特殊招式可单独调整 | 逐招差异与使用细则 |
| 独立终极 | **20元**，特殊招式可单独调整 | 逐招差异与使用细则 |
| 御剑飞行 | **不消耗剑元** | 移动范围、速度与其他细则 |

**9级容量基准：满剑元在不计途中回气时，大致支撑三门标准费用的常规绝技。**前三支拥有三次出剑机会，能够在一个剑术动作中使用这份标准爆发预算；行歌每个动作仍只有两次机会，资源容量与单个动作的出手次数分别处理。

完整容量初稿已确认：2—12级依次为**6、10、14、18、24、26、28、30、40、44、50元**。四支共享，按本职业等级增长，不额外加入感知修正；逐级表见 [数值框架](18-numerical-framework-draft.md)。实际组合仍按每招最终费用与施展时资源结算。

## 5. 血魇伤敌、多段与癫狂触发：主要规则已确认

本轮先细化血魇，再处理其他分支的反击、回气与协作。伤敌饮血、无血目标的广义掠夺及8级主动耗血沿用已有确认；伤敌恢复、斩杀奖励、剑域结算、受伤叠层，以及范围与附加伤害的回元计数已经进一步确认如下。

| 项目 | 已确认规则 | 涉及招式与待定细节 |
|---|---|---|
| 伤敌恢复生命 | **按实际伤害20%恢复**，多段与多名敌人的伤害均计入 | 常态饮血、穿行猎杀、反扑、持续剑域与血影围杀；取整与结算细节待定 |
| 瞬间招式恢复剑元 | **每段有效剑击都回元，每份1元**：同一敌人连续被击伤，每段都能回元；范围攻击也按各次剑击结算 | 常态、穿行、反扑、多段追斩与围杀；附带状态后续伤害等来源细则待定，剑域结算时点见下行 |
| 斩杀奖励 | **额外恢复自身最大生命10%、剑元3元，并获得癫狂2层** | 斩杀归属与结算细节待定 |
| 持续剑域 | **开域立即攻击一次，之后每个自身回合开始再统一攻击域内敌人，并取得饮血与回元收益** | 9级随身移动剑域；饮血20%、每份1元，范围、持续与伤害待定 |
| 被动受伤判定 | **经过防护与减伤后，实际损失自身生命才积蓄癫狂**；完全化解的伤害不触发 | 普通受伤的被动判定；8级主动付出生命获得癫狂的独立招式效果保留 |
| 受伤换取层数 | **每次受伤1层；该次损失达到最大生命10%时额外2层；上限15层** | 每满2层命中＋1、每层剑招伤害＋5%／减伤多2个百分点；持续与计算顺序待定 |
| 范围回元计数 | **每段、每名被击伤敌人分别计数**：一段击伤三人恢复3元；两段都击伤三人恢复6元 | 同一招多段集中于单敌或分散至多敌，均按实际有效剑击结算 |
| 同剑附加伤害 | **对同一敌人的同一剑合并计为一次剑击**；剑招本身与附加伤害合计用于比例回血，不额外增加回元次数 | 与独立的下一段剑击分别处理；附带状态后续伤害等其他来源细则待定 |

剑域在开域与自身回合开始时的攻击，每次按实际有效剑击计数，饮血比例20%、每份回元1元；恢复不超过相应生命与资源上限。攻击段数、持续时间与战后处理继续细化。

伤敌恢复、斩杀奖励、被动受伤叠层与剑域后续结算按对应触发自动处理。主动备用疗伤与8级主动耗血积蓄癫狂仍分别使用附赠动作；被动收益与主动补救按不同能力记录。

### 结算示例：计数与已确认恢复初稿

下表中的 `r` 为已确认饮血比例20%；每份有效剑击恢复1元。各份生命恢复的取整方式仍待确认。

| 情形 | 生命恢复 | 剑元恢复 |
|---|---|---|
| 同一敌人受到三段有效剑击，实际伤害分别为 `D1`、`D2`、`D3` | `r × (D1 + D2 + D3)` | 三份，即3元 |
| 一段范围剑击分别击伤三名敌人 | 按三名敌人承受的实际伤害合计乘以 `r` | 三份，即3元 |
| 两段范围剑击，每段都击伤同样三名敌人 | 按六次实际伤害合计乘以 `r` | 六份，即6元 |
| 一剑对同一敌人造成本体伤害与附加伤害 | 两部分实际伤害合计乘以 `r` | 合并为一份，即1元 |

斩杀额外恢复3元及自身最大生命10%，并获得2层癫狂。例表说明计数与恢复关系，所有恢复与积蓄受相应上限约束。

## 6. 太玄护体反击：逐项确认

本节细化4级护体强化“清辉返照”与7级护身反制绝技“星河倒悬”的后续反击。两者名称仍为候选，首次施展仍分别使用附赠动作与一次出剑机会；后续反击单独记录。

| 项目 | 已确认规则 | 待定细节 |
|---|---|---|
| 反击触发条件 | **护体期间，敌人攻击未命中，或命中后被剑气减伤，都可触发对来袭者的反击** | 距离、伤害与持续时间；频次、费用及命中见下行 |
| 可应对攻势 | **近身、远程与直接伤害法术**：有明确攻击者或施术者的直接攻势，都可用剑气反击 | 反击距离、判定与伤害；持续伤害、环境伤害等其他来源另待讨论 |
| 后续反击的动作占用 | **玩家每次触发时选择是否反击**；不消耗出剑机会、附赠动作或反应 | 具体反击距离与伤害 |
| 反击频次 | **4级与7级两门招式均可对每次符合条件的攻势反击**，从4级起即可连续反制 | 距离、伤害及持续时间 |
| 多段攻势计数 | **每个符合条件的独立攻击阶段都可提供一次反击机会**；同一段的本体与附加伤害合并，独立下一次攻击另算 | 具体攻击来源与判定；来袭多段仍须各自符合未命中／剑气减伤的条件 |
| 反击的剑元费用 | **不额外耗元**，施展护体时支付费用，期间反击由护体能力提供 | 两门护体招式的开启费用 |
| 反击命中 | **独立进行命中判定，具有高精准度**，仍可能落空 | 命中增幅、伤害、防护穿透与距离；目标已有破绽时按第8节受益 |

7级绝技依靠主动伤敌、压退解围，以及护体和反击的强度体现进阶。具体数值与持续时间待定；本节反击适用于这两门招式的护体期间，3级常态护身仍按原有防护能力记录。

## 7. 行歌基础回气与协作：逐项确认

行歌常态剑法提供后续跟进增益，7级绝技引导即时合击，12级终极提供全队增幅与持续御剑呼应。三种配合按不同能力分别记录，保持行歌个人强度低于前三支、偏重团队协作的定位。

| 项目 | 已确认规则 | 待定细节 |
|---|---|---|
| 常态出剑基本回气 | **每次不耗剑元的常态出剑都提供基本回气，即使未命中也可恢复剑元** | 每次恢复1元；跟进机会的施加与刷新见第8节 |
| 常态／7级／12级协作对象 | **实际队伍成员**作为同伴参与配合，各招分别满足自己的距离与攻击条件 | 协作距离与具体攻击形式；12级自身呼应见下行 |
| 常态跟进的协作回气 | **同一份跟进机会，每名同伴首次命中／直接伤害法术对该敌人生效时各奖励一份剑元**；重复攻击不重复领取这份奖励，进攻增益持续期间仍保留 | 持续；每份恢复2元，适用攻击与奖励重合见下行，命中施加与刷新重置见第8节 |
| 常态跟进的适用攻击 | **队伍同伴的武器攻击与直接伤害法术，包括7级协同**，命中或法术对该敌人生效即可享有增益并满足首次回气条件 | 具体增幅、持续与其他攻击来源细则 |
| 7级即时合击的动作占用 | **同伴免费协同出手，不消耗同伴的动作、附赠动作或反应**；行歌施展绝技仍占一次出剑机会并支付剑元 | 具体资源费用、距离／目标条件与其他细则 |
| 7级即时合击的参与与次数 | **每次施展，附近符合攻击条件的同伴各即时攻击同一关键敌人一次** | 附近范围、距离／目标与其他使用细则；每人一次协同攻击不等于完成自身一整套常态连击 |
| 7级同伴协同攻击的类型 | **普通武器攻击或单体伤害戏法**：近战、射手与施法队伍同伴均可用符合距离的基础攻击配合 | 具体攻击选择方式、威力、距离与判定；仍为每名参与同伴一次协同攻击 |
| 7级行歌自身未命中 | **仍可引导合击**：绝技成功施展即可让同伴协同，不要求行歌自己的剑击先命中 | 同伴分别进行自己的攻击判定与协作回气结算 |
| 7级合击的协作回气 | **每名同伴命中各奖励一份**，成功配合的人越多，回气份数越多 | 每份2元，伤害戏法的具体生效判定待细化；奖励重合按下一行处理 |
| 常态与7级回气重合 | **同一次同伴出手同时满足两项回气条件，只取得数值较高的一项**，不叠加两种回气 | 两项均为每份2元；首次成功跟进已经发生，按对应机会记录该同伴的跟进资格 |
| 接应／保护的协作回气 | **成功对同伴提供接应或保护、招式生效时即奖励回气**，不必等待敌人进攻或防护实际化解伤害 | 每份奖励2元；持续保护的后续收益、常态并肩是否适用，以及自用时的收益另行讨论 |
| 12级御剑呼应的触发来源 | **自身与协作范围内队伍同伴的主动武器攻击、直接伤害法术**可触发；**7级合击的同伴免费协同也可触发**，须仍有该同伴本轮的呼应次数 | 具体协作距离与其他攻击来源细则；持续伤害等其他来源未随本项确认 |
| 12级御剑呼应的成功条件 | **攻击命中或伤害法术对敌生效即可**；即使伤害被完全减免，也可跟进 | 范围生效的具体判定与剑击效果 |
| 12级御剑呼应的动作占用 | **自动跟进，不消耗行歌的出剑机会、附赠动作或反应** | 攻击威力与持续时间；开启终极仍占一次出剑机会并支付剑元 |
| 12级御剑呼应的频次 | **自身与每名同伴每轮各一次，在行歌自身回合开始时重置** | 终极持续、协作范围与每次剑击的效果；重新开启终极的处理另定 |
| 12级多段攻势计数 | **整次施展计一次**：多段攻势中有命中或生效，就提供一次跟进机会，仍受每名同伴每轮一次的频次约束 | 独立下一次主动攻击与一招内的多段分别处理；具体效果与范围另定 |
| 12级同伴范围攻势的跟进 | **这一次呼应以小范围飞剑攻击多名生效敌人** | 具体范围、覆盖方式与目标分散时的处理 |
| 12级单体攻势的跟进 | **单体攻势追加单体飞剑，范围攻势采用小范围飞剑跟进** | 具体威力、范围与多目标覆盖方式；自身符合条件的攻势沿用相同呼应方向 |
| 12级后续跟进的剑元费用 | **不额外消耗剑元**：开启时支付终极费用，效果期间的呼应由终极提供 | 开启费用、持续时间与剑击威力 |
| 12级呼应的协作回气 | **这次呼应命中至少一名敌人，合计奖励一份协作回气**；范围命中多敌不增加份数 | 每份2元，具体命中判定待细化，零命中不提供这项奖励 |
| 12级独行呼应 | **自己的符合条件的主动攻击也可每轮触发一次**，次数同样在自身回合开始重置 | 独行时仍获得终极的自身进攻增益；具体威力与持续另定，个人爆发低于前三支的目标保持 |

常态出剑的基本回气与同伴跟进的协作奖励分别结算。同一份跟进机会内，每名同伴完成首次成功跟进后，重复攻击不再取得这份机会的奖励；行歌重新命中施加机会时，刷新持续并重置奖励资格，不叠存多份。同一次同伴出手同时满足常态与7级回气条件，取两项恢复量较高者。接应／保护的费用需逐招细化；成功协作每份2元已确认。

7级即时合击与12级终极的持续御剑呼应分别处理。7级采用普通武器攻击或单体伤害戏法，行歌自身未命中仍可引导，每名同伴命中各奖励一份。12级自身与每名队伍同伴每轮各一次，符合条件的主动攻势，以及7级协同攻击，命中／生效后自动御剑，不占动作或反应、不额外耗元；多段整次施展计一次，单体与小范围跟进分别呼应对应攻势，每次命中合计回气一份。具体范围、威力、持续与其他来源细则继续讨论，协作每份2元已确认。

### 行歌结算示例：只说明次数

- 行歌进行一次常态出剑，即使未命中也取得一份基本回气；跟进机会需要常态剑击命中后施加，完全减免伤害仍可施加。
- 敌人已有一份跟进机会：同伴甲首次命中，行歌取得一份协作回气；甲再次命中不重复领取；同伴乙首次命中，再提供一份。合计两份协作回气，每份2元，合计4元。
- 行歌施展一次7级合击，附近恰好有三名符合攻击条件的同伴：行歌占用一次出剑机会施展绝技，三名同伴各即时攻击一次，均不消耗自己的动作、附赠动作或反应。
- 接应／保护成功对同伴生效时取得对应协作回气；是否后续受到敌人攻击，不影响这次生效奖励的触发。
- 12级终极有效期间，一名同伴施展三段攻击的招式，其中有命中／生效，整次施展只提供一次御剑呼应；本轮这名同伴的呼应次数随后用完。
- 四人队伍中，行歌自身与三名同伴在条件满足时，每轮合计最多四次呼应。每次呼应命中至少一敌，分别奖励一份剑元；一次范围呼应同时命中多人，仍只奖励一份。
- 目标已有跟进机会，同伴的7级协同命中同时满足首次跟进与合击回气：这次同伴出手取两项奖励中较高者。若该同伴仍有12级呼应次数，随后引发一次飞剑；飞剑命中则按呼应的独立剑击奖励一份，前项恢复2元，独立呼应命中再恢复2元。

## 12. 装备、额外动作与援护补全：已确认

- 双持每次出剑只选一把剑计算W；可用附赠动作补一次副手常态出剑，不额外获得整套连贯出剑，不能以该副手出手释放强化或绝技。
- 其他能力提供**额外完整剑术动作**时，仍获得当级整套出剑次数；如果只提供额外一次攻击，则只有一次出剑。副手、免费协同、反击与呼应继续执行各自次数，不自动扩展成完整动作。额外动作只给一次出剑的备选未采用；游戏内动作来源的映射另由MVP验证。
- 血魇3级伤敌血衣：实际伤害10%转为护盾，累计上限最大生命20%，2轮、再次取得刷新。先结算减伤再由血衣承接；没有实际损失自身生命则不取得受伤癫狂。
- 血魇4级穿行／6级追斩实际位移后，获得2轮护甲等级＋2，同名不叠加。血衣15%转化／30%上限的备选未采用。
- 行歌救急治疗与8级解控可援助18米内实际队友；对同伴实际恢复生命、实际解除控制，或成功提供主动保护／接应，按一份协作奖励回气。
- 行歌9级每次施展，按获得保护的队友各奖励一份；持续期间离开／重新进入不重复奖励。自用与被动并肩不提供这些协作奖励；治疗不回气的备选未采用。
- 协作每份3—10级2元，11级起3元；原有常态／7级奖励不叠加、12级范围呼应合计一份等规则保持。

## 13. 持续、削弱叠加与控制清单：已确认

- 持续N轮以施展者的后续回合开始计时，第N次开始先结束到期效果，再处理周期伤害。4轮太清剑域／血海噬灵为开域一次、随后前三次自身回合开始各一次，合计四次；合计五次的备选未采用。
- 重施刷新到期时间，同名不叠加且不重置本轮已用次数；问路首次奖励资格重置的专门规则保持。
- 不同剑招的破甲与减速各取当前最强，各效果独立计时；强效果到期后，尚未结束的较弱效果继续生效。不同名称破甲累加的备选未采用。
- 护体系列取强、职业与招式百分比增伤相加、减伤乘算等已定规则保持。
- 已确认控制清单：束缚、缠绕、定身、击倒、眩晕、麻痹、沉睡；恐惧、魅惑、心智支配；致盲、沉默。清除已有状态不取消持续地面或其他来源，之后仍可能重新施加。
- 自动保障仍仅处理失去行动能力／玩家控制权的关键控制，不把全部清单状态都改为自动消除。

## 14. 伤害归属、分担与剑路：已确认

- 血魇饮血、血衣与斩杀收益来自自身剑类攻击、职业招式及剑域；同一剑本体与附加伤害合并，独立装备持续伤害不另计作有效剑击。所有自身伤害均可取得这些收益的备选未采用。
- 每个敌人死亡事件只奖励一次对应斩杀收益；普通受伤癫狂仍以实际损失自身生命为条件。
- 行歌9级分担覆盖武器、法术、持续与环境伤害，排除主动生命费用。队友先结算减伤与护盾，再转移部分剩余伤害，行歌再结算自身防护；转移伤害不再转移。
- 多个行歌护身重合时只取分担比例最高的一名，等比例取最近施展者。仅分担敌方伤害的备选未采用。
- 普通常规主动攻击选择可见敌人或可见落点；实体墙、封闭门阻挡普通攻击、穿行与冲阵。佩剑御剑完成后自动归手。
- 太玄一线天为穿墙例外：选定剑路即可施展，沿线敌人无需可见。

## 15. 伤害口径、取整与失剑持续：已确认

- 血魇饮血与血衣以减免后的最终伤害值为准，包含对敌人护盾的伤害与超出剩余生命的过量伤害；有实际伤害的有效剑击可回元。仅计实际扣除生命的备选未采用。
- 最终每段每目标伤害、分担伤害向下取整；生命恢复、血衣取得、百分比回元和主动耗血费用向上取整，仍受对应上限限制。
- 天倾／行歌失剑不结束已释放的持续效果；余威与团队增益继续，行歌御剑呼应暂停，取回剑后恢复，不补发错过的呼应。失剑立即结束持续绝技的备选未采用。
