# 东方剑修静态美术资产 · v1

本套依据2026-09-29的[职业总稿](../../docs/20-eastern-sword-cultivator-gdd.md)、[逐招规格](../../docs/19-skill-specifications-draft.md)、[玩家技能说明](../../docs/21-player-facing-skill-text-draft.md)及[美术指南](../../docs/17-bg3-art-style-guide.md)制作。总稿的正式名称优先于较早讨论文件的候选名称。

打开 [gallery.html](gallery.html) 按技能名、技术ID、分支和类别浏览。点击图片打开母版；每张图下可下载相应尺寸。画廊在生成过程中显示完成状态，以 `manifest.json` 为准确清单。

## 范围与复用

82项独立原创图像：5枚职业／子职业徽记、44枚技能图标、12枚被动标识、17枚状态图标、2枚资源标识、2张背景／宣传插画。图像使用内置ImageGen逐项生成，不将一张拼图拆成多个技能交付。

2026-10-07 已从职业中移除召剑；本套保留其历史画稿与制作清单，当前 Mod 不再绑定或打包该独立图标，活动美术绑定为81项。

- 初阶／成熟疗伤以及10—11级同名技能进阶复用该技能图标，不把每次数值升级做成新的按钮。
- 近身／御剑两种施展方式通常复用同一招式图标，二者都表达对应剑术；共同入门近身剑术与御剑术有各自图标。
- 前三支主动解控、抗控基础及反应脱困采用共同图标；行歌“拂尘”保留独立图标。
- “凝气成剑”“改换重点目标”“剑气伤害切换”的图标是供实际UI接入选择的制作资产；不因此增加新动作、资源或技能机制。
- 被动的美术标签如“剑心／感知御剑”“深厚体魄”用于整理素材，不冒充新确认的玩家正式特性名称。
- 同系列护体可复用剑气护体、清辉返照、星河倒悬的技能图标作为对应状态；独立反击提示另有标识。
- 剑元与癫狂的容量、层数和数值由游戏UI绘制，图片不烘焙文字、数字或进度条。
- 祖师与跨界传承只通过背影和陌生遗迹表现；不固定脸部、钥匙具体形状或新的剧情事实。

## 文件结构

| 目录／文件 | 内容 |
|---|---|
| `masters/` | 生成的原尺寸PNG母版，保留透明通道 |
| `exports/hotbar_64/` | 技能／被动／状态／资源的64px制作版本 |
| `exports/controller_144/` | 同组144px透明版本 |
| `exports/tooltip_380/` | 同组380px透明淡出版本 |
| `exports/class_300/` | 徽记300px版本 |
| `exports/class_hotbar_64/` | 徽记64px补充制作版本；接入时核对实际职业模板 |
| `previews/` | 画廊预览；不作为导入源图 |
| `manifest.json` | 每项的ID、中文名、设定依据、提示词、完成情况、母版与生成路径 |
| `prompts.jsonl` | 全套提示词，每资产一行，可用于有针对性的重做 |
| `review/` | 分支总览、实际64px对照与透明度统计 |

四支初版配色：太玄青白、天倾赭金、血魇深绯、行歌青绿与旧金。颜色属于美术方向；天倾赭金不代表火焰伤害，血魇的广义掠夺也不要求敌人有鲜血。

修订采用独立的 `-v2` 等文件名。画廊和清单指向当前选用版本；`revision_history`保留此前母版、提示词及生成路径，旧稿仍留在对应目录。连城图标另存四次连击更清楚的第二稿。

## 制作与验证

- 使用内置 `image_gen`，没有CLI／API密钥路径；每张独立生成并保存到当前项目。
- 徽记用金属纹章画法，技能及功能标识用发光手绘轮廓。PNG缩放与补充透明边距使用Pillow，保留原生成母版，不靠代码替代生图。
- 生产脚本位于 `../production/`：`create_catalog.py`维护清单；`manage_assets.py`登记图片、导出尺寸、刷新画廊和验证文件。
- `manifest.json`记录参考文档的SHA-256，后续设计更新可据此判断资产是否需要调整。
- PNG是制作与导入源图。DDS转换、图集、Icon ID、ClassDescriptions命名及游戏内呈现由Toolkit接入验证；本套不修改职业规则或已有Mod。
- 原版参考只用于分析画法，没有把原版图标复制到本套原创资产中。

图片尺寸与Alpha验证不等于游戏内验证。全套完成后还需在实际快捷栏／手柄菜单／悬浮说明中审阅小尺寸辨识、同类图标区别及透明边缘。
